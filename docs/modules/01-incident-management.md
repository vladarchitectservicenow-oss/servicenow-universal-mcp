# Инциденты (Incident Management)

**Модуль ServiceNow:** Incident (`incident`)

## Назначение
Управление жизненным циклом инцидентов — от создания до закрытия. Восстановление нормального сервиса после сбоев.

## Что умеет MCP-инструмент

| Инструмент | Описание |
|------------|----------|
| `incident_create` | Создать новый инцидент: описание, приоритет, категория, группа назначения |
| `incident_list` | Получить список инцидентов с фильтрацией по статусу, приоритету, группе |
| `incident_get` | Получить детали конкретного инцидента по номеру |
| `incident_update` | Обновить инцидент: статус, заметки, переназначить |
| `incident_stats` | Статистика: группировка по статусам, приоритетам, overdue |

## Примеры использования

```
> Создай инцидент P1 для падения продакшен-базы, категория Database, группа DBA
> Покажи все критические инциденты открытые больше 24 часов
> Сколько у нас просроченных инцидентов?
> Переведи INC0012345 в статус Resolved с комментарием "Починили"
```

## Ключевые поля

- `number` — номер (INC...)
- `state` — 1=New, 2=In Progress, 3=On Hold, 6=Resolved, 7=Closed
- `priority` — 1 (Critical), 2 (High), 3 (Moderate), 4 (Low), 5 (Planning)
- `assignment_group` — группа назначения
- `category` — Hardware, Software, Network, Database
